# Viora Model Packs

This file organizes the available Viora extension package files into a simple model lineup so they are easier to understand and choose from.

## Overview

Each package is a release build of the Viora extension. The names now follow a consistent pattern so the version and purpose are easier to identify.

## Model Pack Guide

### 1. Viora-Model-01-Legacy.zip
- Purpose: The earliest release in the project.
- Characteristics: Basic structure and the original build style.
- Best for: Testing the first experience or using a legacy package.

### 2. Viora-Model-02-Improved.zip
- Purpose: A small upgrade from the first release.
- Characteristics: Cleaner layout and better packaging.
- Best for: Users who want a slightly more polished early build.

### 3. Viora-Model-03-Expanded.zip
- Purpose: A more feature-rich build.
- Characteristics: Broader script coverage and more complete functionality.
- Best for: Users who want more capability without moving into the later 4.x line.

### 4. Viora-Model-04.0-Core.zip
- Purpose: The first major 4.x release.
- Characteristics: Stronger sidepanel logic and more advanced content handling.
- Best for: Users wanting a more capable baseline release.

### 5. Viora-Model-04.2-Polished.zip
- Purpose: A refined 4.x package.
- Characteristics: Updated UI, cleaner settings structure, and improved polish.
- Best for: A balanced mix of stability and features.

### 6. Viora-Model-04.3-Complete.zip
- Purpose: The most complete general-purpose release in the main line.
- Characteristics: Fullest feature set and best overall package quality.
- Best for: Recommended choice for most users.

### 7. Viora-Model-04.4-Styled.zip
- Purpose: A styled release in the newer family.
- Characteristics: Visual improvements and refinement over the earlier 4.x builds.
- Best for: Users who prefer a more polished presentation.

### 8. Viora-Model-04.5-Styled.zip
- Purpose: A later styled release.
- Characteristics: Continued cleanup and presentation updates.
- Best for: Users who want a newer styled package.

### 9. Viora-Model-04.6-Styled.zip
- Purpose: The newest styled release in the lineup.
- Characteristics: Latest visual packaging and layout improvements.
- Best for: Users who want the newest styled build.

## Recommendation

If you want the safest and most complete choice, start with Viora-Model-04.3-Complete.zip.
