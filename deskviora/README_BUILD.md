# Build DeskViora.exe

This folder contains the DeskViora source and a GitHub Actions workflow that builds a real Windows executable on GitHub's Windows runner.

## Build on GitHub
1. Commit and push the contents of this folder to GitHub.
2. Open the Actions tab in the repository.
3. Run the workflow named "Build DeskViora.exe".
4. Download the generated artifact named "DeskViora-windows".

The resulting file is the standalone executable at dist/DeskViora.exe.
